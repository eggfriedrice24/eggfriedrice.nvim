1. INTRODUCTION                                     *eggfriedrice-introduction*

eggfriedrice is a dark colorscheme that leans into its name: yolk-yellow
literals, rice-cream text, and scallion-green strings on a navy background
inspired by the halcyon VSCode theme. Token roles follow One Dark Pro: red
identifiers, purple keywords, green strings, and blue operators where One
Dark Pro uses cyan. Yellow is the signature: it carries functions, types and
builtins plus everything One Dark Pro paints orange. Fields and properties
are red on declaration and access alike.

Token roles are enforced consistently across legacy |:syntax| groups,
treesitter captures, and LSP semantic tokens, and are tuned against
TypeScript, JavaScript, Go, Rust, Java, Python, Lua, CSS, HTML, YAML, JSON,
TOML, and Markdown.

==============================================================================
2. REQUIREMENTS                                     *eggfriedrice-requirements*

- Neovim >= 0.9
- 'termguicolors' (set automatically on load)

==============================================================================
3. USAGE                                                   *eggfriedrice-usage*

Load the colorscheme: >lua

    vim.cmd.colorscheme("eggfriedrice")
<
Calling `setup()` is only required to change defaults, and must happen
before `colorscheme` is executed.

==============================================================================
4. CONFIGURATION                                   *eggfriedrice-configuration*

                                                          *eggfriedrice.setup()*
Defaults: >lua

    require("eggfriedrice").setup({
      transparent = false,    -- no background; use the terminal's
      italic_comments = true, -- italic comments
      dim_inactive = false,   -- darker background in inactive windows
      on_colors = nil,        -- fun(colors) palette hook
      on_highlights = nil,    -- fun(highlights, colors) group hook
    })
<
transparent                                         *eggfriedrice-transparent*
    When true, editor, float, and sidebar backgrounds are set to NONE so
    the terminal background (and its opacity/blur) shows through.

italic_comments                                 *eggfriedrice-italic_comments*
    When false, comments are rendered upright.

dim_inactive                                       *eggfriedrice-dim_inactive*
    When true, inactive windows use the darker background shade. Ignored
    while `transparent` is set.

==============================================================================
5. HOOKS                                                   *eggfriedrice-hooks*

on_colors                                             *eggfriedrice-on_colors*
    Receives the complete palette table (base colors, semantic aliases,
    and derived backgrounds) before any highlight groups are built.
    Mutate it in place: >lua

    require("eggfriedrice").setup({
      on_colors = function(c)
        c.green = "#b0e070"
        c.comment = "#8a8578"
      end,
    })
<
on_highlights                                     *eggfriedrice-on_highlights*
    Receives the final table of highlight groups and the palette after
    all groups are built and before they are applied. Mutate or add
    groups in place: >lua

    require("eggfriedrice").setup({
      on_highlights = function(hl, c)
        hl.CursorLineNr = { fg = c.red, bold = true }
        hl["@punctuation.special"] = { fg = c.orange }
      end,
    })
<
==============================================================================
6. LUALINE                                               *eggfriedrice-lualine*

A lualine theme ships with the plugin: >lua

    require("lualine").setup({
      options = { theme = "eggfriedrice" },
    })
<
Mode colors match |mini.statusline| groups: normal is yellow, insert is
green, visual is purple, replace is red, command is cyan.

7. PALETTE                                               *eggfriedrice-palette*

  Role                            Key         Hex ~
  Variables, fields, keys, tags   red         #e06c75
  Keywords, decorators            purple      #c084fc
  Functions, types, literals      yellow      #ffc940
  Operators                       blue        #6cb8ff
  Strings                         green       #60e654
  Escapes, enum members, accents  cyan        #78e2d6
  Text                            fg          #d8d3c3
  Punctuation                     fg_dark     #a8a396
  Comments                        comment     #8695b7
  Line numbers, dividers          fg_gutter_ui #586480
  Decorative gutter               fg_gutter   #46516c
  Background                      bg          #0d111a
  Dormant (unassigned)            orange      #fc9a2c

A bright tier lifts each accent 0.04 OKLCH lightness with its hue held
and fills ANSI slots 9 to 15 in |:terminal| and in the extras:
`red_bright`, `green_bright`, `yellow_bright`, `blue_bright`,
`purple_bright`, `cyan_bright`, `fg_bright`.

Diff backgrounds are tints at one OKLCH lightness and chroma in each
accent's hue; search backgrounds are blends. Both are computed at load
time, so palette overrides via |eggfriedrice-on_colors| carry through.

8. EXTRAS                                                 *eggfriedrice-extras*

The palette rendered for other programs lives under `extras/` in the
repository. Every file there is generated from `lua/eggfriedrice/colors.lua`
by `make extras` (or `nvim -l scripts/extras.lua`), and CI fails when the
committed output drifts, so the extras never lag behind the editor.

  App                        File                              ~
  Ghostty                    extras/ghostty/eggfriedrice
  fzf (0.36+)                extras/fzf/eggfriedrice.sh
  zsh (z-sy-h, autosuggest)  extras/zsh/eggfriedrice.zsh
  fast-syntax-highlighting   extras/fsh/eggfriedrice.ini
  Starship                   extras/starship/eggfriedrice.toml
  tmux (3.3+)                extras/tmux/eggfriedrice.tmux
  lazygit                    extras/lazygit/eggfriedrice.yml
  bat, Sublime Text          extras/bat/eggfriedrice.tmTheme
  Hyprland, hyprlock         extras/hyprland/eggfriedrice.conf
  Lua                        extras/lua/eggfriedrice.lua
  GTK CSS (waybar, ghostty)  extras/gtk/eggfriedrice.css
  rofi                       extras/rofi/eggfriedrice.rasi
  dunst                      extras/dunst/eggfriedrice.conf
  btop                       extras/btop/eggfriedrice.theme
  eza                        extras/eza/eggfriedrice.yml
  opencode                   extras/opencode/eggfriedrice.json
  Slack                      extras/slack/eggfriedrice.txt
  Discord (client mods)      extras/discord/eggfriedrice.theme.css
  Zen Browser                extras/zen/userChrome.css
  Helium, Chromium browsers  extras/chromium/manifest.json
  frameit (0.2+)             extras/frameit/eggfriedrice.toml
  anything else              extras/palette/eggfriedrice.json

Each generated file starts with its install hint. The hyprland, lua, gtk
and rofi files expose the whole palette as named variables, and the tmux
file also sets it as `@eggfriedrice_*` user options. Every extra renders
from a role map, and the palette JSON emits all of them under "apps",
so the design export and the generated files agree by construction.
Shell roles match the editor: commands are yellow like functions, quoted
words green like strings, `$vars` red like variables, redirections blue
like operators.
The palette JSON carries the full token set of the design system,
including the semantic names each extra maps from.
